# Binary Size Analysis: Release Profile Optimization
Date: 2026-01-29

## Configuration Added to Cargo.toml
```toml
[profile.release]
lto = "thin"
codegen-units = 1
panic = "abort"
strip = "symbols"
opt-level = 3
```

## Binary Size Comparison (sermon.exe)

| Metric | Value |
|--------|-------|
| BEFORE | 23,933,440 bytes (22.83 MB) |
| AFTER  | 14,889,984 bytes (14.20 MB) |
| SAVED  | 9,043,456 bytes (8.63 MB) |
| % Reduction | 37.8% |

## Feature Decisions

### Symphonia (audio-engine)
- Status: KEPT `features = ["all"]`
- Reason: ADR 0007 requires full codec support (FLAC, WAV, MP3, AAC, ALAC, Vorbis, AIFF, MKV/WebM)

### rusqlite (library)
- Status: KEPT `features = ["bundled"]`
- Reason: Windows reliability + FTS5 availability

## Notes
- Build time increased from ~1m47s to ~2m46s (+55% due to LTO and single codegen unit)
- Trade-off acceptable for 37.8% binary size reduction
